# 问象 · 易经用户提问内容分析

一个用于上传并分析易经用户提问数据的静态看板原型，支持 CSV、Excel 和 JSON。

## 功能

- 自动识别提问内容、时间、用户与产品端字段
- 清洗无效提问并标注缺失字段
- 一级问题类型、二级场景和标准问题归类
- 趋势、类型分布、App/Web 差异及问题明细展示
- 时间、产品端、一级类型和二级类型联动筛选

## 本地运行

```bash
python3 -m http.server 8765
```

然后访问 <http://127.0.0.1:8765/>。

## 验证

```bash
node --test logic.test.js
node --check app.js
```
